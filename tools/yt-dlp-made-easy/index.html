? How to Install yt-dlp & FFmpeg

yt-dlp works best alongside FFmpeg (required for merging high-res video and audio tracks). Pick your system's quick one-liner below:

Windows (Winget)
winget install yt-dlp ffmpeg
Windows (Scoop)
scoop install yt-dlp ffmpeg
macOS (Homebrew)
brew install yt-dlp ffmpeg
Linux (Ubuntu / Debian)
sudo apt install ffmpeg python3-pip && pip install -U yt-dlp
Linux (Arch)
sudo pacman -S yt-dlp ffmpeg
Android (Termux)
pkg update && pkg install python ffmpeg && pip install -U yt-dlp
Protip

YouTube serves separate video and audio streams for 1080p, 1440p, and 4K resolutions. Installing ffmpeg allows yt-dlp to automatically merge the highest quality video and audio tracks seamlessly into an MP4 or MKV file without quality loss.
